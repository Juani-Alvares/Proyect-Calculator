# Calculadora científica

Calculadora web de una sola página, lista para abrirse directamente en un navegador.

## Uso

Abrí `index.html` con tu navegador. No hace falta instalar dependencias ni ejecutar comandos.

## Estructura

```text
Project - Calculator/
├── index.html          # Estructura y botones de la calculadora
├── assets/
│   ├── css/
│   │   └── styles.css  # Diseño adaptable y tema oscuro
│   └── js/
│       └── app.js      # Operaciones, memoria y manejo de la interfaz
└── README.md           # Esta guía
```

## Funciones incluidas

- Operaciones básicas, paréntesis, porcentajes, fracciones y potencias.
- Trigonometría en grados o radianes, inversas e hiperbólicas.
- Logaritmos, raíces, factorial, constantes `π` y `e`.
- Memoria (MC, MR, M+, M−), `Ans`, modo oscuro y atajos de teclado.
